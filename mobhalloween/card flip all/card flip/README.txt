MobVision Halloween Stage — new tarot-card artwork

OBS Browser Source > Local File > stage.html; recommended size 1672 x 941.
Right-click the Browser Source in OBS > Interact. Click to flip and reveal; click again to reset. R = reveal, X = reset.

Front image: card-front.png. Reveal image: card-back.png. Replace those PNGs with the same names for future event artists/tracks. The text is part of the reveal image, so to change it make a new card-back.png.

The existing side-stage masked silhouette and persona animation are retained and remain configurable in settings.js.

IMPORTANT: The revealing side is NOT mirrored. The CSS rotates its back face by 180deg, correctly compensating for the card's rotation in 3D. Do not manually flip the PNG.
